# Urban Wear — American Dark Streetwear

Aplikasi e-commerce streetwear bergaya Amerika dengan tema gelap (`#151515`), off-white (`#F2F0EB`), dan aksen orange (`#FF5A1F`).

## Struktur File
- `index.html` — Struktur halaman, katalog, modal, dan drawer.
- `style.css` — Gaya kustom, latar belakang kolase American Style, dan status filter.
- `app.js` — Logika interaktif keranjang, wishlist, pencarian, filter, riwayat pesanan, dan checkout WhatsApp.
- `vercel.json` — Konfigurasi header keamanan HTTP untuk deployment di Vercel.
